# Kbd

Keyboard keys and the Count badge. **Kbd** shows a shortcut in menus, tooltips, buttons and the palette footer. Pass `keys` as the platform's glyphs: ⌘ ⇧ ⌥ ↵ on macOS, and the words Ctrl, Shift, Alt, Enter elsewhere. **Count** is a pill number: neutral (`line`), `polar` (actionable, e.g. commits to pull on the Pull button), `conflict`, or `quiet` (bare `ink-muted` number, used in sidebar sections).

Specimen: [`../specimens/components/Kbd.html`](../specimens/components/Kbd.html). Reference implementation: `GitLama.Kbd` in `reference/bundle.js`, props in `reference/index.d.ts`.
