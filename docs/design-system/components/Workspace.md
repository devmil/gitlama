# Workspace

The whole window put together from the system: toolbar with Compass, repo tabs, sidebar on `ground`, and the History and Detail islands. History is focused, so its selection is solid `polar`, while Detail's file selection is `polar-soft`. Use it as the reference composition for `workspace_shell.dart`. Detail always sits below History, separated by a horizontal splitter. At widths under 1100px the sidebar collapses to a 56px icon rail.

Specimen: [`../specimens/components/Workspace.html`](../specimens/components/Workspace.html). Reference implementation: composition only, not an export.
