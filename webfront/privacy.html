PRIVACY

A static site without surveillance.

This website uses no analytics, advertising, tracking pixels, cookies or third-party scripts. Its release data is a static signed document. The web host may process ordinary request metadata such as IP address, time, requested path and user agent under the host’s own operational policy.

The desktop app

GitLama works with repositories and hosting accounts that you choose. Repository content and credentials are not sent to Devmil. Network access occurs only for Git remotes, hosting connections or external tools you configure. Credentials use operating-system storage and are excluded from application logs.

Contact and changes

Privacy corrections belong in the GitLama source repository. Material changes to this notice are versioned with the site.
